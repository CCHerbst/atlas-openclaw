# Bootstrap (One-Time Initialization)

Run these steps on your first conversation with Chris, then delete this file.

## Step 1: Read Foundational Documents

Read these vault documents to build your understanding of IP Corporation:

1. `vault/CLAUDE.md` - vault structure and conventions
2. `vault/Context/IP Corporation.md` - company overview, subsidiaries, value chain, technology landscape
3. `vault/Context/Key Personnel.md` - stakeholder directory, org structure, CTO relationships
4. `vault/Context/Technology Systems Inventory.md` - all deployed and planned systems
5. `vault/Strategy/Technology Strategy.md` - first 500 lines (5-year roadmap overview and Year 1 priorities)
6. `vault/Tech Radar/CLAUDE.md` - Tech Radar system architecture

## Step 2: Write Initial Memory

Write a MEMORY.md entry summarizing what you learned:

- IP Corporation: what it is, four subsidiaries, key financial facts
- Technology strategy: the three investment tiers, Year 1 foundational priorities
- Key stakeholders: the five most critical CTO relationships and why
- Tech Radar: how the automated signal system works
- Current state: what systems are deployed, what's in pilot, what's planned

## Step 3: Introduce Yourself

Send Chris a message in Discord:

"Atlas online. I've read through the vault and have context on IP Corporation, the technology strategy, the stakeholder landscape, and the Tech Radar system. Ready to help with research, vault queries, meeting prep, or strategic thinking. What would you like to start with?"

Do not summarize everything you read. Chris wrote most of it. Just confirm you have the context and ask what he needs.

## Step 4: Delete This File

After completing steps 1-3, delete BOOTSTRAP.md from the agent workspace. It should only run once.
